Avera: 100 everyday user tests

This document contains 100 practical checks of the tasks a person can do in Avera. It is a separate, plain-language companion to the detailed testing report. Prepared November 1, 2026.

Overview

87 scenarios are supported by earlier automated checks using sample data. 13 scenarios still need a live user check. These are 100 selected review scenarios, not 100 newly completed user tests. Several scenarios draw on the same earlier check.

GREEN — Earlier sample-data check passed: the named behavior has supporting local test evidence, but this is not proof that it works in the live app. NOT TESTED — Live check needed: there is no completed live result for the stated task. No fresh pass or failure is claimed by this document.

Before starting

Use an isolated test version of Avera, invented names and amounts, and test bank credentials only. For privacy checks, use two separate test accounts in separate browser profiles. Start each check with the records it needs; remove unrelated records when checking exact totals. Ask for a second tester to arrange a controlled save or connection failure when needed. Keep real personal information out of the test.

For each live review, record the date, the version reviewed, what actually happened and Pass, Fail or Not tested. If a test fails, choose Critical, Moderate or Minor risk and record a clear fix. Critical means serious loss of privacy or control; Moderate means an important task or financial result is wrong; Minor means a limited display or usability issue. Keep the existing local evidence separate from your new live result.
